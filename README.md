This project is a MATLAB program for a LEGO Mindstorms EV3 robot that drives autonomously by following a wall on its right, but switches to keyboard control whenever its color sensor detects a blue, green, or yellow floor tile. It uses two drive motors on ports A and B, a lift motor on port C, a color sensor on port 3, an ultrasonic sensor on port 2, and two touch sensors: port 1 for emergency stop and port 4 for bump/reverse-turn behavior.

In autonomous mode, the robot follows a right-hand wall on black floor. It drives forward and uses the ultrasonic sensor to measure distance to the wall. If the wall distance exceeds 65 cm, it stops and performs a single right turn, then disarms the turn logic until the wall comes back within 50 cm. This prevents repeated spinning in open areas. When the color sensor reads red, the robot stops briefly for about one second and then resumes. If the robot is on black or red and Touch Sensor 4 is pressed, it reverses for 0.7 seconds and then turns left 90 degrees.

When the color sensor detects blue, green, or yellow, the robot stops and enters manual mode. In manual mode, the up and down arrow keys drive forward and backward, the left and right arrow keys pivot the robot, and the T and R keys raise and lower the lift motor. If no key is pressed, the motors brake. The robot stays in manual mode while the floor color remains blue, green, or yellow, and returns to autonomous mode once the color changes. Pressing Touch Sensor 1 at any time stops the robot and exits the program.

The main configurable values are drive speed in manual mode (25), left and right autonomous drive speeds (40.125 and 40), turn speed (20), lift speed (15), the wall-gone threshold (65 cm), the wall re-arm threshold (50 cm), and the manual-mode trigger colors (blue, green, and yellow). The slight difference between the two autonomous drive speeds is intentional to correct real-world drift.

To run the project, connect the EV3 brick to MATLAB with the EV3 Hardware Support Package installed, verify the port mapping, place the robot on the course, and run the script. Press Touch Sensor 1 to stop and exit. Known issues: the black beep branch in manual mode is unreachable because black is not in the trigger color list, yellow has no beep pattern, red only pauses unless Touch 4 is also pressed, and the wall-following logic assumes a right wall will eventually reappear.
